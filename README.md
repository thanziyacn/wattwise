# ⚡ WattWise – Smart Electricity Calculator

## 📌 Project Overview
WattWise is a simple web-based application that helps users estimate their monthly electricity consumption based on daily usage of common appliances like fans, air conditioners, and lights.

The goal of this project is to create awareness about energy usage and help users make smarter decisions to reduce electricity consumption.

---

## ❗ Problem Statement
Many people are unaware of how much electricity they consume daily. This leads to:
- High electricity bills
- Inefficient energy usage
- Lack of awareness about consumption patterns

---

## 💡 Solution
WattWise provides an easy way to calculate monthly energy usage by:
- Taking input of daily usage (in hours)
- Calculating total units consumed
- Giving feedback on usage (Good / High usage)

---
